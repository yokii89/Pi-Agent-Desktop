## English

- Paste text, screenshots, and copied local files into the session input by right-clicking or pressing Ctrl+V.
- When adding multiple attachments, PiDesk skips duplicate file paths and still accepts images after the file attachment limit is reached.

## 简体中文

- 在会话输入框中右键点击或按 Ctrl+V，即可粘贴文字、截图和复制的本地文件。
- 批量添加附件时会跳过重复的文件路径，文件附件达到上限后仍可添加图片。
