## English

- Session history and remote session previews now show the latest user prompt, making recent work easier to identify.
- Improved preview handling for image-only prompts and unusual message text.
- Fixed an edge case where assistant text containing role-like text could corrupt the session preview.

## 简体中文

- 会话历史和远程会话预览现在显示最新用户提示词，更容易识别最近处理的任务。
- 改进仅包含图片的提示词和特殊消息文本的预览处理。
- 修复助手回复中包含类似角色标记的文本时可能错误覆盖会话预览的问题。
