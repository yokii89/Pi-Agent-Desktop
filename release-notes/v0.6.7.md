## English

- Compatible extensions can display an agent workspace with an agent relationship graph, execution status, and per-agent conversations. Expand the workspace for a larger view and switch between agents while preserving each conversation's reading position.
- Keep extension-owned child sessions out of the main session history while preserving their saved conversations.
- Open workspaces in VS Code more reliably, including folders with special characters in their paths, with clearer feedback when opening fails.
- Improve idle session cleanup and background process tracking, and make the live-session refresh control more compact.

## 简体中文

- 兼容扩展可展示智能体工作区，集中查看智能体关系图、执行状态和各智能体的对话；支持放大查看，切换智能体时保留各自的阅读位置。
- 扩展管理的子会话不再混入主会话历史列表，同时保留已保存的对话记录。
- 更可靠地在 VS Code 中打开工作目录，支持路径中的特殊字符，并在打开失败时提供更清晰的提示。
- 改进空闲会话回收与后台进程跟踪，并精简存活会话的刷新控件。
