A round of reliability for the moments when pi needs to ask *you* something — plus a scroll fix that was easy to hit and easy to explain away.

## When the assistant needs your answer

- **Questionnaires come back where you're typing.** The floating question card above the input bar finds its own window again, so multi-choice questions with side-by-side previews render as designed instead of quietly disappearing.
- **Nothing waits in silence.** When an extension asks for a choice, a confirmation, a line of text or a block of editing, a real dialog now opens in the window. Before this, an unanswered request could leave a tool spinning forever with no way to reply except ending the session.
- **Every way out works.** Escape, the Cancel button, stopping the run, or ending the session all resolve the request immediately — the assistant is told "the user didn't answer" instead of hanging on it.
- **Background sessions say whose turn it is.** A session that is stuck waiting for you shows the same amber question mark in the sidebar that a blocked form already did.
- **Extension notices land as toasts.** Short messages an extension wants you to see now appear as in-app notices rather than vanishing into the terminal.

## Running two PiDesk windows at once

- **Extensions stop crossing over.** With the installed app and a development copy open side by side, each window keeps its own extension panels and dialogs; one no longer hijacks the other's.

## Fixes & polish

- Scrolling a few lines while already pinned to the bottom no longer bounces you back up.
- The "@" marker in the input bar now follows your accent color.

## 简体中文

这一版主要收拾「pi 要问你话」的那些时刻，另外修了一个很容易碰到、又很容易被当成正常行为的滚动问题。

### 助手要你作答的时候

- **问卷回到你打字的地方。** 输入栏上方的浮层问卷重新能找到自己的窗口了，带对照预览的多选题按设计出现，不再悄悄消失。
- **不再无声等待。** 扩展要你选一项、确认一次、填一行字或改一段内容时，窗口里会真的弹出对话框。以前这类请求没人应答，工具能一直转圈，除了结束会话没有别的办法。
- **每一条退路都通。** Esc、点「取消」、中断本轮、结束会话，都会立刻把请求结算掉——告诉助手「用户没答」，而不是吊在上面。
- **后台会话会说明在等谁。** 正在等你作答的会话，侧栏会亮起和「表单被挡住」同一个琥珀色问号。
- **扩展的提示变成气泡。** 扩展想让你看到的一句话，现在以应用内通知出现，不再说完就消失。

### 同时开两个 PiDesk 窗口

- **扩展不再串门。** 安装版和开发版并排开着时，各自保留自己的扩展面板与对话框，不会再把对方的抢走。

### 修复与细节

- 已经贴底时再滚几行，不再被弹回上方。
- 输入栏里的「@」标记改随主题色。
