Messages you send while the agent is working now wait in a drawer you can still change your mind about.

## Conversation

- **Queued messages wait in a drawer.** A message you send while the agent is running no longer drops into the transcript — it waits in a tray right above the input bar, so what hasn't been delivered yet is visible at a glance. The tray rises out when the first message arrives and slides back when the last one leaves.
- **Change your mind about any of them.** Each row carries its own actions: switch between *Steer* (delivered before the agent's next step) and *Later* (handled once the current run ends), take it back into the input bar and rewrite it, or delete it outright.
- **Set the order you want.** With two or more messages waiting of the same kind, a handle appears beside each row: drag it up or down, or focus the handle and press ↑ / ↓. The order you set here is the order the agent actually receives them in.
- **The two kinds stay easy to tell apart** — steering is a bolt in your accent colour, later is an amber arrow — and the drawer follows your theme, light mode included.

## 简体中文

智能体还在跑时你发出的消息，如今停在一个还能反悔的抽屉里。

### 对话

- **排队消息改在抽屉里等。** 智能体运行中发出的消息不再落进对话流，而是停在输入栏正上方的托盘里——还没交出去的是什么，一眼就能看清。第一条到达时托盘升出来，最后一条离开时收回去。
- **每一条都还能改。** 行上自带三个动作：在「插话」（下一次模型调用前送达）与「稍后」（本轮结束后处理）之间切换、取回输入栏重新编辑，或者直接删除。
- **顺序你说了算。** 同类消息满两条时，每行左侧出现手柄：按住上下拖动，或聚焦手柄后按 ↑ / ↓。在这里排好的顺序，就是智能体实际收到它们的顺序。
- **两种消息一眼分得开**——插话是一枚用你主题色的闪电，稍后是一支琥珀色的箭头——托盘跟随你的主题，浅色档同样清楚。
