## Copy a whole reply, in one click

- **Reply footer.** Every finished reply now ends with two quiet buttons and a timestamp. Copy as Markdown keeps headings, lists, links and code fences intact for pasting into notes or docs; copy as plain text strips the formatting so it reads cleanly anywhere.
- **Only the answer, not the process.** Thinking and tool calls stay out of the copied text. Replies with no visible text (for example a pure tool round) get no footer.
- **Shown only when the reply is done.** The footer appears after the whole reply has finished, so it never flickers between steps.

## Long drafts stay in the input box

- **The input box stops growing.** Really long prompts now scroll inside the input area instead of pushing the conversation off screen.
- **The caret stays in view.** Recalling an earlier message or pasting a long text keeps the cursor visible — no more hunting for where you were.

## 简体中文

每条完成的回复都带上了自己的页脚：整条复制成 Markdown 或纯文本，完成时间一目了然；超长草稿也不会再把输入框撑破。

### 整条回复，一键取走

- **回复页脚。** 每条完成的回复末尾现在有两个低调的按钮和一个时间：复制为 Markdown 会保留标题、列表、链接与代码块，粘到笔记或文档里格式依旧；复制为纯文本会去掉格式，在任何地方都能直接读。
- **只取答案，不取过程。** 思考过程与工具调用不会进入复制内容；没有可见正文的回复（例如只调用了工具的轮次）不会出现页脚。
- **回复结束才出现。** 页脚在整条回复完成后才显示，不会在工具间歇里一闪一闪。

### 超长草稿，留在输入框里

- **输入框不再无限长高。** 很长的提示词会在输入区内滚动，而不是把对话流顶出屏幕。
- **光标始终可见。** 召回历史消息或粘贴长文后，光标会自动留在可视区，不用再到处找自己写到了哪。
