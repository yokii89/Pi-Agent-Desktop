Tables and code blocks can now leave the conversation as pictures, and tables look like proper cards instead of a bare grid.

## Send a table as an image

- **Two quiet buttons on every table.** Hover a table (or tab to it) and a small toolbar fades in at its top-right: copy as image, or copy Markdown. Nothing moves while you are just reading.
- **The image is the whole table.** It is rendered off-screen, not screenshotted, so a long table is never cut off at the edge of the window — no floating panels, no half rows.
- **Copy Markdown puts the table back.** Bold, inline code, links and column alignment are preserved, so a table can be pasted straight back into a prompt and keep working.
- **Rounded table cards.** Tables now sit in a rounded card with horizontal scrolling, so a wide table stays inside the conversation column instead of stretching it.

## Code blocks: image or text

- **Copy as image.** The copy button on a code block now offers two actions: copy as image, or copy as text. The image keeps syntax highlighting and full-width lines, so long lines are no longer clipped.
- **Copy as text is the old behaviour**, unchanged.

## Smaller things

- **The round-edit summary follows your reading size.** Its title, filenames and counts now scale with the conversation font-size setting instead of being pinned to one size.

## 简体中文

表格和代码块现在都能一键变成图片离开对话；表格也不再是裸露的网格，而是一张圆角卡片。

### 表格，直接发成图片

- **每张表格右上角有两个低调按钮。** 鼠标悬停（或键盘聚焦）时淡入「复制为图片 / 复制 Markdown」，只是阅读时不会在你眼前晃。
- **图片是整张表格。** 它在后台离线渲染而不是截屏，所以多长的表格都不会被窗口边缘切断，浮层也不会混进图里。
- **复制 Markdown 能把表格装回去。** 粗体、行内代码、链接和列对齐都会保留，粘回对话框里仍然是一张能解析的表。
- **表格变成圆角卡片。** 表格放进带横向滚动的圆角卡片里，很宽的表格被收在对话列内，不再把整列撑开。

### 代码块：复制成图，或复制成文

- **复制为图片。** 代码块上的复制按钮现在有两个动作：复制为图片、复制为文本。图片保留语法高亮和完整行宽，长行不再被截掉半截。
- **复制为文本就是原来的行为**，一字未改。

### 其他小改动

- **本轮编辑汇总跟着你的阅读字号走。** 标题、文件名与统计行现在跟随「对话流字号」设置缩放，不再固定在一种大小。
