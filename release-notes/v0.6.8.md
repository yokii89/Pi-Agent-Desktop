## English

- Browse the file tree alongside a file preview, and adjust the width of each pane by dragging or using the keyboard.
- Use compact search popovers in file, PDF, and Office previews to find content while keeping more of the document visible.
- Open the agent workspace in a movable, resizable floating window, adjust the graph and task-detail split, and navigate larger agent graphs more easily.
- Expand subtask and workflow notifications to inspect execution status, results, and usage, with quick actions to copy results or the full transcript path.
- Compatible companion apps can display session model and thinking settings, including for saved sessions.
- Make application icon previews more consistent and reduce unnecessary startup messages when checking available shells.

## 简体中文

- 支持并排浏览文件目录与文件预览，可通过拖动或键盘调整两侧宽度。
- 文件、PDF 和 Office 预览采用紧凑搜索浮层，查找内容时保留更多文档阅读空间。
- 智能体工作区支持可移动、可调整大小的浮窗，可调整关系图与任务详情的比例，更方便地浏览大型智能体关系图。
- 展开子任务和工作流通知即可查看执行状态、结果与用量，并快速复制结果或完整记录路径。
- 兼容的伴侣应用可展示会话的模型与思考设置，同时支持已保存的历史会话。
- 统一应用图标预览的视觉尺寸，并减少检查可用 Shell 时产生的无关启动日志。
