## English

### Improvements
- Choose whether to open web links in a conversation in the sidebar browser or your system browser.
- Keep your file tree scroll position when returning from a file preview.

### Fixes
- Open local Markdown links more reliably, including Windows paths and links to directories. Local HTML files open in the sidebar browser, and directories open in File Explorer.
- Show the correct file selection hint when the code review panel uses a stacked layout.

## 简体中文

### 改进
- 点击会话中的网页链接，可选择在侧栏浏览器或系统浏览器中打开。
- 从文件预览返回文件树时，保留原有滚动位置。

### 修复
- 改善 Markdown 本地链接的打开体验，支持 Windows 路径与目录链接；本地 HTML 文件在侧栏浏览器打开，目录在资源管理器打开。
- 修正代码审阅面板上下布局时的文件选择提示。
