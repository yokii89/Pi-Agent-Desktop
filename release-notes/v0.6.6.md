## English

- Preserve session drafts when starting a new task fails, including when another draft has already occupied the home composer.
- Resolve local extension package paths from the settings directory, matching pi's behavior.
- Paste text, screenshots, and copied local files into the session input by right-clicking or pressing Ctrl+V.

## 简体中文

- 新任务启动失败时保留会话草稿；即使首页输入框已被另一份草稿占用，也不会丢失原草稿。
- 从设置目录解析本地扩展包路径，与 pi 的行为保持一致。
- 在会话输入框中右键点击或按 Ctrl+V，即可粘贴文字、截图和复制的本地文件。
