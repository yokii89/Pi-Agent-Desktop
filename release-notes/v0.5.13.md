This update adds more ways to personalize agent activity, makes remaining context easier to see, and improves the Windows taskbar icon.

## Personalize agent activity

- Choose from five running markers in Appearance settings, with live previews. Your choice appears in the input bar and while the agent is working.
- The thinking-level control in the input bar now has an animated matrix and comet display. Use the keyboard or scroll wheel to change levels as well as dragging.

## See context at a glance

- The context ring now highlights remaining capacity. Its color shifts from teal to amber and red as the context fills, while the details show used and total tokens.

## Windows taskbar

- The installed app now uses its PiDesk icon on the Windows taskbar.

## 简体中文

本次更新增加了 agent 运行状态的个性化选项，让上下文剩余量更醒目，并修正 Windows 任务栏图标。

### 个性化运行状态

- 在「外观」设置中从五种运行标记里选择样式，并通过实时预览查看效果。所选标记会显示在输入栏和 agent 运行状态中。
- 输入栏的思考等级控件新增动态矩阵与彗星效果。除了拖动，也可以使用键盘或滚轮切换档位。

### 一眼查看上下文余量

- 上下文圆环现在突出显示剩余容量。随着上下文逐渐占满，颜色会从青绿转为琥珀色和红色；详细信息仍显示已用与总 token 数。

### Windows 任务栏

- 安装后的应用现在会在 Windows 任务栏正确显示 PiDesk 图标。
