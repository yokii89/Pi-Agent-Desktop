A conversation you can steer, a sidebar that tells you how each session ended, and a theme color that reaches everywhere.

## Conversation

- **Talk to the agent while it works.** The send button now offers *Later* (queue the message for after the current turn) and *Steer* (hand it to the running turn right away). Queued messages can be edited in place — `/` and `@` references included — or withdrawn one by one, and one click puts the whole queue back into the input box.
- **Select text and act on it.** Highlighting text in a conversation raises a small toolbar right above the selection: copy it, or add it to the input box.
- **The sidebar shows how a session ended.** A green check for a normal finish, a red warning when the run failed or was cut off, and a yellow question mark when the agent is blocked waiting for an answer from you. They appear only while the session isn't focused, and clear as soon as you open it.
- **Stop and retry are reported honestly.** Stopping while a retry is still pending no longer marks the turn as failed, and an early stop no longer looks like a completed run.
- **Tool calls show how long they actually ran**, falling back to elapsed time when the tool doesn't report its own.
- **Session titles come from pi**, so the sidebar shows the name pi recorded instead of a locally generated one.
- **Export** moved into a submenu and can produce a single self-contained HTML file of the conversation.
- **Code blocks**: line numbers no longer sit on their own background strip, and code lines are evenly spaced.

## Appearance

- **15 theme colors.** Your own message bubbles, the send button's active state, and the effects on the highest thinking level all follow the color you pick.
- **A capybara companion** can keep you company in the input bar — six moods that follow what the session is doing, and a small surprise if you click it.
- The sidebar's sections expand and collapse more smoothly, and the running-state border glow no longer costs frames.
- Row actions in the sidebar fade in place instead of shifting the title.

## Browser & inspector

- Picking an element for a screenshot no longer flashes white.
- The inspector window has a pin button to keep it above other windows.
- Opening and closing menus over the browser panel no longer makes the page flash.
- The right sidebar opens a start page when there is nothing to show, and page tabs can be closed.
- The right panel's drag handle no longer fights with the embedded page; it appears on hover as a thin line.

## Models & MCP

- **Settings → Models** shows each model's output limit in its own column, and the expanded capability view is lighter to scroll.
- Provider and model logos are the actual brand marks now.
- MCP server switches and exposure levels apply immediately instead of graying out the whole page.

## Extensions

- The Extensions page is redesigned, and each local resource can be enabled or disabled on its own.
- **@pidesk/view-sdk 0.5.1** is published on npm: list options can carry a Markdown preview, text can be toned (muted / success / warning / danger), and access-mode metadata is declared once through a helper.

## Fixes & polish

- Sessions are grouped under the deepest matching project instead of needing an exact path match.
- The "more actions" menu in the sidebar no longer shows a scrollbar.

## 简体中文

能边跑边说话的对话，会告诉你每一轮怎么结束的侧栏，以及一个铺满各处的主题色。

### 对话

- **agent 在跑的时候也能说话。** 发送键现在有 *稍后*（排到当前回合结束后）与 *插话*（直接交给正在跑的回合）两种发法。排队中的消息可以就地编辑（`/` 与 `@` 引用照常可用）、逐条撤回，也可以一键清空并全部回填到输入框。
- **选中即用。** 在对话里划选文字，选区上方会出现一条小工具条：复制这段文字，或者放进输入框。
- **侧栏会告诉你每一轮是怎么结束的。** 正常完成是绿色对勾，运行失败或被截断是红色警告，agent 卡在等你回答时是黄色问号。它们只在会话没有焦点时出现，打开会话即消失。
- **停止与重试的状态不再说谎。** 在重试等待期按停止，不会再被记成"失败"；提前中断也不会显示成"已完成"。
- **工具调用会显示实际执行了多久**；工具自己没报耗时的时候，退回用墙钟时间。
- **会话名来自 pi**，侧栏显示的名字与 pi 记录的一致，不再另存一份本地标题。
- **导出**收进了二级菜单，并且可以把整段对话导出成一个独立的 HTML 文件。
- **代码块**：行号不再压在自己的背景色带上，代码行距也均匀了。

### 外观

- **15 档主题色。** 你发出的消息气泡、发送键的激活态、最高思考等级的特效，都会跟着所选颜色走。
- **水豚伙伴**可以蹲在输入栏陪你——六种情绪姿态跟随会话状态，点它一下还有小彩蛋。
- 侧栏分区收展更顺滑，运行态边框流光也不再吃帧。
- 侧栏行内操作改为原地淡入淡出，不再把标题挤动。

### 浏览器与检查器

- 圈选元素截图不再闪白。
- 检查器浮窗新增置顶开关，可以压在其他窗口上面。
- 浏览器面板上开关菜单不再闪一下页面。
- 右侧栏没有内容可显示时打开启动页，页面页签可以关闭。
- 右侧栏的拖拽把手不再和内嵌页面抢手：悬停时以一条细线现身。

### 模型与 MCP

- **设置 → 模型** 新增输出上限列，能力展开态的滚动更轻。
- 厂商与模型图标换成了真正的品牌 logo。
- MCP 服务器的开关与暴露级别改为立即生效，不再整页置灰。

### 扩展

- 扩展页改版，本地资源可以逐项启用 / 停用。
- **`@pidesk/view-sdk` 0.5.1** 已发布到 npm：list 选项可以带 Markdown 预览，文本可以带状态色（弱化 / 成功 / 警告 / 危险），访问模式元数据也能通过一个辅助函数只声明一次。

### 修复与打磨

- 会话按最深的匹配路径归属项目，不再要求路径完全一致。
- 侧栏「更多操作」菜单不再出现滚动条。
