A small patch: one fix for notifications, one squeeze of extra room for the file panel.

## Fixes & polish

- **Clicking a Windows notification now brings PiDesk up.** Tapping the system toast used to do nothing — the window stayed buried. It now comes to the front as expected, even when another app currently has focus.
- **More room for the file panel's Markdown preview.** Switching between preview and source moved into a compact icon in the panel header, so the toolbar no longer eats a whole row in a narrow sidebar.
