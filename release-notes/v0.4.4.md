Split the terminal in two, keep web links inside the browser panel, and take an update in one click from the sidebar.

## Terminal

- **Two panes in the terminal panel.** Two toolbar buttons split it left/right or top/bottom, and you can drag the divider to set the ratio. Splitting reuses a terminal that's already running instead of starting another session, and unsplitting leaves both as tabs — panes are a way to look at terminals, not a way to kill them.
- **Tab completion is now a choice** (Settings → Environment): *Cycle* steps through candidates one at a time and is the default; *List all* puts every candidate on screen in one Tab. In PowerShell *List all* needs a second Enter to run the selected candidate — the reason it isn't the default. Takes effect for terminals opened after the change.
- **Ctrl+Shift+C / Ctrl+Shift+V** copy and paste in the terminal. Previously those keystrokes arrived as Ctrl+C and could interrupt a command that was still running. Pasted text is not executed until you press Enter.

## Embedded browser

- Links that request a new window now open as a **tab in the browser panel** (up to 8 pages) instead of a window floating outside it — middle-click and Ctrl+click included.
- Sites that really need their own window still get one: popups that specify a size (the usual OAuth and payment shape), named targets, and Shift+click. Sign-in flows are unchanged.
- Page tabs carry the site's **favicon**, with a globe as fallback.

## Staying up to date

- When a newer version is available, an **Update** button appears next to *Settings*: one click starts the download, the button shows progress inline, then turns into **Restart** to finish the install — or **Retry** after a failed download. With the sidebar collapsed you get the icon plus a small dot; nothing shows when you're already up to date.

## Fixes & polish

- The interface language you picked survives a restart — it used to fall back to "follow system".
- Session titles in the sidebar are shortened at the width actually available instead of at a fixed character count.
- Diffs in the review panel size to their content; a short diff no longer sits in a fixed-height box with a scrollbar over empty space.
- The actions on your own messages are icons with tooltips now (Copy / Resend).
- The settings window highlights its section list with a pill that glides from one entry to the next.
- Settings → About shows the PiDesk repository link alongside the pi one.

## For extension developers

- `@pidesk/view-sdk` 0.2.0 is published to npm under the public `pidesk` organization, so an extension can depend on the View SDK instead of vendoring it.

## 简体中文

终端一分为二，网页链接留在浏览器面板里，更新在侧栏点一下就能装。

### 终端

- **终端面板支持分屏。** 工具栏两个按钮分别做左右分屏与上下分屏，中间的分隔条可以拖拽调整两窗格比例。分屏会优先复用一个已经在跑的终端，而不是再开一个会话；取消分屏也只是收起来，两边的会话都还在页签里。
- **Tab 补全方式变成一个选择**（设置 → 环境）：*循环切换* 是默认，按 Tab 逐个替换候选词；*列出全部* 一次把候选清单铺出来。PowerShell 下 *列出全部* 选中候选后要多按一次回车才执行——这正是它不做默认的原因。改动只对新开的终端实例生效。
- **Ctrl+Shift+C / Ctrl+Shift+V** 在终端里复制、粘贴。以前这两个键会被终端当成 Ctrl+C，正在跑的命令可能被打断；粘贴进来的内容仍需你自己按回车执行。

### 内嵌浏览器

- 需要开新窗口的链接现在落在**浏览器面板的页签**里（最多 8 个页面），不再甩出一个浮在应用外的窗口；中键与 Ctrl+左键同样进页签。
- 确实需要独立窗口的站点照旧拿到一个窗口：自带尺寸的弹窗（OAuth、支付常见形态）、命名窗口，以及 Shift+左键。登录流程没有变化。
- 页签显示站点**图标**，没有图标的站点回退成地球仪。

### 版本更新

- 检测到新版本时，侧栏「设置」右侧出现 **「更新」** 按钮：点一下开始下载，按钮上直接显示进度，下载完成变成 **「重启」** 收尾安装；下载失败则给出 **「重试」**。侧栏收起时只剩图标加一颗小红点；已是最新版本时什么都不显示。

### 修复与打磨

- 选好的界面语言重启后仍然保留——以前会退回「跟随系统」。
- 侧栏的会话标题按实际行宽省略，不再按固定字数硬切。
- 审查面板的 diff 按内容高低展开，短 diff 不再被关在一个固定高度的盒子里、下面空一片却带滚动条。
- 自己发出的消息，悬浮操作改成纯图标加悬浮提示（复制 / 重新发送）。
- 设置浮窗左栏的选中底色变成一块在条目间滑动的药丸。
- 设置 → 关于 在 pi 开源地址旁边补上了 PiDesk 开源地址。

### 给扩展开发者

- `@pidesk/view-sdk` 0.2.0 已发布到 npm 的公开 org `pidesk`，扩展可以直接依赖 View SDK，不必再 vendor 一份。
