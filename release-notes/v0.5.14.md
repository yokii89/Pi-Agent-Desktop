This update adds LaTeX formulas to Markdown and improves everyday interactions in the input bar and background process panel.

## Read mathematical formulas

- Inline and display formulas now render in conversations, thinking content, and Markdown previews. Both dollar delimiters and LaTeX parenthesis or bracket delimiters are supported.
- Display formulas stay together during streaming, even when they contain blank lines. Wide formulas scroll horizontally, and invalid formulas remain readable as source.
- Formula rendering loads on demand and includes local fonts, so it works without an internet connection.

## Smoother workspace interactions

- Clear the selected project directly from its icon in the input bar, while keeping the project selector available beside it.
- File references in messages now share the input bar's file chip styling.
- The thinking-level control has a cleaner inactive track, and the background process panel has a more streamlined layout.

## 简体中文

本次更新为 Markdown 增加 LaTeX 公式渲染，并改善输入栏与后台进程面板的日常操作。

### 阅读数学公式

- 对话正文、思考内容和 Markdown 预览支持行内与独立公式，兼容美元符号以及 LaTeX 的圆括号、方括号分隔符。
- 流式输出时，公式内部的空行不会将公式拆开。较宽的公式可横向滚动，无法解析的公式会保留源码供阅读。
- 公式渲染按需加载，字体随应用提供，无需联网。

### 更顺手的工作区操作

- 可直接点击输入栏中的项目图标清除所选项目，旁边的项目选择入口仍可继续使用。
- 消息中的文件引用与输入栏文件标签采用一致的样式。
- 思考等级控件的未激活轨道更加简洁，后台进程面板的布局也得到精简。
