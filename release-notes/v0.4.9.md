A background wallpaper you pick yourself, a sidebar you can drag into order, and model logins inherited straight from pi.

## Background wallpaper

- **Any picture or clip on your machine.** Settings → Personalization → Wallpaper fills the whole window behind the app with a file you choose, image or video. Nothing is copied or uploaded — PiDesk just reads it from where it already sits.
- **A dimmer that keeps text readable.** The mask slider runs 0–100: higher fades the artwork back, lower lets it show through.
- **Video behaves itself.** Background clips play silently on a loop, pause while the window is hidden, and never auto-play if your system asks for reduced motion.
- **The conversation gets its own surface.** With a wallpaper on, the cards in the session stream turn translucent and lightly frosted, while popovers, sidebars and dialogs keep solid ground — and reduced transparency puts everything back to flat colors.

## A sidebar that sorts the way you work

- **Long-press to drag.** Hold a project — or a session inside one — and pull it to a new place; an accent line shows where it will land, and the order is kept for next time.
- **No mouse required.** The row menu carries Move up / Move down for the same result one key at a time.
- **Pinned sessions still lead.** A brand-new session lands at the top of the list under your pinned block, so it shows up without breaking the order you set.

## Models inherited from pi

- **"Inherit from pi".** If a provider is already signed in through pi, Settings → Models links it here instead of asking you to paste the key again. The row is badged "From pi", and if that login later disappears on the pi side it is marked invalid and can no longer be activated.
- **pi's own files stay untouched.** Inheriting stores a reference, never a copy: tokens and every other credential field are left as pi wrote them, and un-linking an entry doesn't sign you out anywhere.
- **The model you choose now sticks.** Picking a model in the input bar writes through to pi's default, so nothing quietly swaps it back on the next round — and with no session running it simply takes effect on the next start instead of telling you the session isn't up yet.

## Brand icons where you actually look

- **The model chip shows who it is.** The chip in the input bar leads with the vendor's own logo, by model family when one gateway serves several makers.
- **Command rows show the tool.** Each shell row opens with the badge of whatever really runs — pnpm, git, node, python — so you can scan a tool call without reading the command line.

## Two new input buddies

- **Peashooter and Steve.** Two pixel characters join the buddy line-up, each with its own snack for the feeding easter egg. The picker in Settings → Personalization is now labeled "buddy figures", since they stopped being only animals.

## Fixes

- Expanding the right sidebar no longer slides the whole window sideways and springs it back; the tab bar now scrolls itself without dragging the page along.

## 简体中文

自己挑的背景壁纸、可以拖动排序的侧栏，以及直接从 pi 继承过来的模型登录。

### 背景壁纸

- **本机图片或视频都能当背景。** 设置 →「个性化 → 壁纸」选一个文件，整个应用背景就铺上去了。素材不复制、不上传，只在原位置读取。
- **用遮罩强度保住可读性。** 0–100 可调：调高背景退开、文字更清晰，调低则让画面透出来。
- **视频知道分寸。** 动态背景静音循环播放，窗口隐藏时暂停，系统要求减弱动效时不自动播放。
- **对话流有自己的表面。** 开了壁纸以后，会话流里的卡片变成半透明加轻微磨砂，而弹层、侧栏、对话框仍保持实底；系统要求减弱透明度时全部退回实色。

### 按你的习惯排的侧栏

- **按住就能拖。** 长按项目行、或项目里的会话行，拖到新位置，落点有一条主题色横线提示，松手后顺序记住。
- **不用鼠标也行。** 行菜单里给「上移 / 下移」，键盘和读屏同样能整理顺序。
- **置顶区仍然在最前。** 新会话出现在置顶块下方的第一位，不会把你排好的顺序打乱。

### 从 pi 继承模型

- **「从 pi 继承」。** pi 里已经登录过的厂商，设置 →「模型」直接引用过来，不用再贴一次密钥。条目带「来自 pi」徽标；那边之后登出了，这里会标成失效并且无法激活。
- **不动 pi 自己的文件。** 继承只建立引用、不复制：密钥和其他凭据字段都保持原样，取消继承也不会把你在 pi 的登录弄掉。
- **选的模型现在说了算。** 在输入栏挑定模型后会写进 pi 的默认值，下一轮不会被悄悄换回去；没有正在运行的会话时也不再提示「会话未启动」，而是下次启动直接生效。

### 在你真正会看的地方放品牌图标

- **模型芯片露出厂商。** 输入栏的模型芯片前面带上品牌图标；同一个网关挂着多家模型时按模型家族取图标。
- **命令行看得出在跑什么。** 每条 shell 工具行开头是真正执行的主体徽标——pnpm、git、node、python——不用读命令原文就知道这条在干什么。

### 两位新的输入栏伙伴

- **豌豆射手与史蒂夫。** 伙伴列表新增两位像素形象，投喂彩蛋也各有各的零食。设置 →「个性化」里的入口改叫「伙伴形象」——毕竟已经不只有动物了。

### 修复

- 展开右侧上下文侧栏不再把整个页面横向推出去再弹回来；页签条自己滚动定位，不再带着页面一起动。
