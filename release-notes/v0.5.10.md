This update makes workspace navigation easier to tailor, adds useful file previews, and improves session review.

## Workspace and files

- Resize the left sidebar and keep its width between launches.
- Choose whether the workspace button opens File Explorer or VS Code.
- Keep the file tree selection when switching away and back.
- Preview tables, notebooks, and PDFs in the file panel. Compact JSON files are formatted for easier reading.

## Sessions and browser

- Compare workspace snapshots to review the changes made during a session round.
- Close the last page in the built-in browser without an extra page appearing.
- The unreliable login-state import option has been removed; sign in directly on websites in the browser.
- Collapsed tool and thinking rows use tighter spacing, and sidebar animations have been smoothed out.

## Visual polish

- The start page feature cards now use a clearer theme-colored hover state.

## 简体中文

本次更新让工作区导航更易调整，增加实用的文件预览，并改进会话回顾体验。

### 工作区与文件

- 可调整左侧边栏宽度，应用会在下次启动时保留该宽度。
- 可选择工作区按钮默认用资源管理器还是 VS Code 打开。
- 切换离开再返回时，保留文件树中的选择位置。
- 文件面板支持预览表格、Notebook 和 PDF；紧凑 JSON 文件会自动整理格式，阅读更轻松。

### 会话与浏览器

- 通过工作区快照对比，查看本轮会话产生的文件改动。
- 内置浏览器关闭最后一个页面后，不再自动出现额外页面。
- 已移除不稳定的登录态导入功能，请直接在内置浏览器中登录网站。
- 收起的工具行与思考行间距更紧凑，侧栏收展动画也更平滑。

### 视觉细节

- 启动页功能卡片悬停时会以更清晰的主题色突出显示。
