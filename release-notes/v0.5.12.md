This update adds in-place file editing, Windows accent color support, clearer browser inspection, and a choice when closing the window.

## Read and edit files

- Edit text files directly in the Files panel and save when ready. Markdown files can be edited in source view.
- Search, select, copy, and quote file content. Source view keeps your selection, scroll position, and undo history when switching between reading and editing.
- Unsaved changes prompt you before leaving a file. If the file changes on disk, choose whether to overwrite it or reload the disk version. Saving preserves the original line endings.
- More source files have syntax highlighting, including PowerShell, shell scripts, Go, Ruby, Dockerfiles, TOML, C#, Kotlin, and Swift.

## Appearance and browser tools

- Choose the Windows system accent color in Appearance settings. PiDesk follows system color changes automatically and adjusts text and focus colors for readability in light and dark themes.
- Accent colors now apply more consistently to controls, selections, terminal focus, and usage charts.
- The browser inspector makes the selected element, its size, and box measurements easier to read. Adjust styles with live preview, or turn it off to keep a draft and apply it when ready.
- Copy CSS adjustments for the AI, discard pending changes, or clear temporary overrides. Style changes remain temporary until you apply them to your project.
- The embedded browser stays aligned with its panel when the app interface is zoomed.

## Closing the window

- Closing the window offers a choice between hiding PiDesk in the tray and quitting, with the affected sessions, terminals, and background processes shown before you decide.
- Hide to tray is the default choice. You can remember your preference and change it later in General settings.

## 简体中文

本次更新带来文件就地编辑、跟随 Windows 强调色、更清晰的浏览器检查器，以及关闭窗口时的选择确认。

### 阅读与编辑文件

- 在「文件」面板直接编辑文本文件，完成后手动保存。Markdown 文件可切换到源码视图编辑。
- 支持查找、选中、复制和引用文件内容；源码阅读与编辑之间切换时，保留选区、滚动位置和撤销历史。
- 离开未保存的文件前会提示处理改动；磁盘文件被外部修改后，可选择覆盖或重新加载。保存时保留原有换行格式。
- 更多源码文件支持语法高亮，包括 PowerShell、Shell、Go、Ruby、Dockerfile、TOML、C#、Kotlin 和 Swift。

### 外观与浏览器工具

- 在「外观」设置中选择跟随 Windows 系统强调色，系统颜色变化后自动同步，并根据深浅主题调整文字与焦点颜色的可读性。
- 控件、选中状态、终端焦点和用量图表更一致地使用主题强调色。
- 浏览器检查器更清晰地展示当前元素、尺寸与盒模型。调整样式时可实时预览，也可关闭实时预览，保留草稿后再手动应用。
- 可复制 CSS 调整给 AI、放弃待应用的更改或清除临时覆盖。样式调整仍是临时预览，需要应用到项目后才会永久保存。
- 缩放应用界面时，内置浏览器能与面板保持正确对齐。

### 关闭窗口

- 关闭窗口时，可选择隐藏到托盘或退出；确认前会展示受影响的会话、终端和后台进程。
- 默认选择隐藏到托盘。可记住本次选择，也可稍后在「常规」设置中更改。
