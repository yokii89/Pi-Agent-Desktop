## English

### Easier mobile pairing

- Open a dedicated mobile pairing dialog directly from the sidebar.
- Follow clearer QR-code pairing steps, see when an invitation expires, and generate a new code when needed.
- Search and select projects before approving a phone, and review its granted permissions after pairing.
- Manage the relay connection, pause or reconnect, and revoke phone access from the same dialog.

### Remote session improvements

- Load conversation history incrementally and retrieve older messages while keeping recent activity in sync.
- View visible tool results on a compatible phone, with tool categories and error states preserved.
- Improve connection cleanup when pausing or exiting, and allow phone access to be revoked while disconnected.
- Strengthen checks when reading shared session history and keep hidden content, thinking, tool arguments, and local absolute paths out of remote messages.

Mobile remote access remains a preview and requires a compatible phone app and a trusted relay service. PiDesk must remain running and connected on your desktop.

## 简体中文

### 更便捷的手机配对

- 从侧栏直接打开独立的手机配对窗口。
- 使用更清晰的扫码配对引导，查看邀请剩余时间，并在需要时重新生成二维码。
- 授权前搜索并选择项目，配对后查看手机已获授的权限。
- 在同一窗口中管理中转连接、暂停或重新连接，并撤销手机访问权限。

### 远程会话改进

- 增量加载会话历史，支持读取更早的消息，并持续同步最近的会话动态。
- 在兼容的手机应用中查看可见的工具结果，保留工具分类与错误状态。
- 改善暂停连接和退出时的连接清理，支持在断开连接时撤销手机授权。
- 加强共享会话历史的读取校验，避免向远端传递隐藏内容、思考、工具参数和本地绝对路径。

手机远程访问仍为预览功能，需要兼容的手机应用与可信的中转服务，电脑上的 PiDesk 需要保持运行并连接中转。
