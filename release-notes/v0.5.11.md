This update reduces memory use from idle sessions, improves file search results, and makes session activity easier to follow.

## Sessions and memory

- Idle background sessions now release their processes after 30 minutes without use, freeing memory and space for other sessions. In General settings, choose 15, 30, 60, or 120 minutes, or turn automatic cleanup off.
- Sessions you are viewing, running tasks, scheduled tasks, pending interactions, and live background jobs stay protected. Session history is preserved; returning to a reclaimed session starts its process again.

## Search and activity feedback

- File search ranks exact names and filename prefixes higher, making the intended file easier to find.
- A compact activity label with a subtle shimmer distinguishes waiting for the model from active work, with clearer transitions when output begins.
- The input companion gives clearer feedback for thinking, switching sessions, completion, interruption, and errors.
- Desktop notifications use your latest message to help identify the task that just finished.

## 简体中文

本次更新减少闲置会话的内存占用，优化文件搜索结果，并让会话运行状态更清晰。

### 会话与内存

- 后台会话默认在闲置 30 分钟后自动结束进程，释放内存与并行会话名额。可在「常规」设置中选择 15、30、60 或 120 分钟，也可关闭自动回收。
- 正在查看、正在运行、定时任务占用、等待交互或仍有存活后台任务的会话会受到保护。会话历史完整保留，返回已回收的会话时会重新启动进程。

### 搜索与状态反馈

- 文件搜索优先展示文件名精确匹配与前缀匹配的结果，更容易找到目标文件。
- 紧凑的文字状态配合柔和微光效果，展示等待模型响应与运行状态，开始输出时的状态切换更清晰。
- 输入栏伙伴更清楚地反馈思考、切换会话、完成、中断和出错等状态。
- 桌面通知优先使用最新一条用户消息，方便辨认刚刚完成的任务。
