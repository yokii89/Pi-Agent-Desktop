This update fixes returning to PiDesk from Windows desktop notifications.

- Clicking a task notification brings the existing PiDesk window to the front and opens the associated conversation, including when the window is minimized or hidden in the system tray.
- Fixes an issue where clicking a notification during development could open the Electron welcome screen.
- Development and installed versions use separate notification activation links to avoid opening the wrong version.

---

**Full Changelog**: https://github.com/yokii89/Pi-Agent-Desktop/compare/v0.5.14...v0.5.15

## 简体中文

本次更新修复了点击 Windows 桌面通知返回 PiDesk 的问题。

- 点击任务通知会将已有的 PiDesk 窗口带到前台，并打开对应对话；窗口最小化或隐藏到系统托盘时也能恢复。
- 修复开发时点击通知可能打开 Electron 欢迎页的问题。
- 开发版与安装版使用独立的通知唤回链接，避免打开错误的版本。
