## English

### Improvements
- Open a live session in Settings to inspect its details, including process ID, working directory, activity, and conversation information. Background and prewarmed sessions remain visible in the list.
- End idle session processes from their details after confirmation. Running sessions are protected, and conversation history and background project processes are preserved.

### Fixes
- Improve PDF preview compatibility and local font and image resource loading.
- Make keyboard page navigation more reliable in paginated document previews.
- Refresh code review changes more promptly as workspace files change.

## 简体中文

### 改进
- 在设置的存活会话列表中点击会话，可查看进程 ID、工作目录、活动时间和会话信息，列表包含后台与预热会话。
- 支持在详情页二次确认后结束空闲会话进程；运行中的会话受到保护，会话历史和后台项目进程予以保留。

### 修复
- 改善 PDF 预览兼容性，以及本地字体和图片资源的加载。
- 改善分页文档预览的键盘翻页体验。
- 工作区文件变化后，代码审阅改动列表刷新更加及时。
