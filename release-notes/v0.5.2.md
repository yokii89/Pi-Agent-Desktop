A small release: the model credential form grows into a real dialog, and the input bar learns to remember.

## Adding a model provider or gateway

- **The credential form is a dialog now.** Adding or editing used to be a strip of six fields wedged under the list, where every label lived in the placeholder and vanished the moment you typed. Fields now stand in a single column with their labels above them, and the dialog stays put while you work — only the middle scrolls.
- **Only the fields that apply show up.** Base URL and API protocol appear when you pick a gateway, and stay hidden for a vendor PiDesk already knows. The preferred model comes as a picker over the active provider's models, with a switch to type an ID by hand.
- **Errors point at the field.** A missing name, key, or Base URL is flagged right where it belongs instead of in a toast at the corner of the window.
- **Removing a credential asks first.** Deleting one — or unlinking a login inherited from pi — now says what it will cost before doing it, and makes clear that unlinking leaves your pi login alone.
- Small touches: an eye toggle on the key field, vendor logos in the provider list, and icon buttons for activate / edit / remove in each row.

## Typing

- **↑ and ↓ walk back through what you sent in this session.** Press ↑ with an empty input bar and your last message comes up; keep pressing to go further back. Change even one character and the recalled line is yours — the next ↑ returns to normal cursor movement. Messages from a restored session count too.

## Fixes & polish

- **Question options show all their choices.** A long list of answers used to collapse into a short scroll box, so an option could sit out of sight and get missed. Lists now grow with their content; only diagnostic lists and the file preview's source column keep a capped height.
- **The change list fits more files.** Each row now shows just the file name, with the full path on hover. Shared directory prefixes used to eat the width and truncate both ends.

## 简体中文

一个小版本：模型凭据表单升级为真正的对话框，输入栏学会回顾你说的话。

### 添加模型厂商或网关

- **凭据表单变成对话框了。** 以前新增/编辑是列表下方一条塞了六个字段的横条，每个字段的说明都写在占位符里，一输入就消失。现在字段单列铺开、名称挂在上方，对话框固定不动，只有中间字段区滚动。
- **该出现的字段才出现。** 选网关类厂商才展开 Base URL 与 API 协议，PiDesk 本来就认识的厂商完全不显示这两项；偏好默认模型做成从当前厂商的模型里挑，也可以切回手填 ID。
- **报错贴着字段。** 漏填名称、密钥或 Base URL，提示就出现在对应字段下面，不再甩到窗口角落的气泡里。
- **移除凭据先确认一次。** 删除一份凭据、或取消一份从 pi 继承的登录，都会先说清后果再动手，并明确告诉你：取消继承不会动 pi 那边的登录。
- 零碎改进：密钥栏加了显示/隐藏小眼睛，厂商列表带品牌 logo，列表行的激活/编辑/移除改成图标按钮。

### 输入

- **↑ / ↓ 回看本会话发过的内容。** 输入栏空着时按 ↑ 唤出上一条，继续按往更早翻；只要你改了一个字，这条召回内容就归你了——下一次 ↑ 恢复正常的光标移动。恢复历史会话读回来的消息同样能召回。

### 修复与细节

- **答题列表把选项一次看全。** 选项一多就会被折进一条带内滚的小盒子，答案藏在滚动条里容易漏选；现在列表随内容全量展开，只有诊断类列表和文件预览的源码列保留封顶高度。
- **变更列表放得下更多文件。** 每行只显示文件名，完整路径靠悬浮查看。以前公共的目录段把宽度吃掉，两端一起被截断。
