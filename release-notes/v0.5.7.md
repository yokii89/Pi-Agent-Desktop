Updates now remember the installer they downloaded, so the next updates only fetch what actually changed — and update problems leave a trail you can actually read.

## Faster updates after the first one

- **Differential updates actually kick in now.** PiDesk used to re-download the full installer on every update. After an update has been downloaded once, PiDesk keeps it as a baseline, so later updates transfer only the changed parts — for the recent releases that turns a ~103 MB download into roughly 2 MB.
- **Update issues leave a log.** Key update steps (checking, differential downloads, falling back to a full download, installing) are now recorded to a log file, so a stalled or odd-looking update can be diagnosed instead of guessed at.

更新包完整下载过一次之后会被记住，此后的更新只拉取真正变化的部分；更新出问题时也有日志可查了。

### 首次更新之后，只下差量

- **差量更新真正生效。** 此前每次更新都会重新下载完整安装包；现在完整下载过一次后，PiDesk 会把它留作差量基准，之后的更新只传输变化的部分——以近期版本为例，同样的更新从约 103 MB 降到约 2 MB。
- **更新问题有日志可查。** 检查、差量下载、回退全量、安装等关键步骤现在会记录到日志文件，更新卡住或表现异常时有据可查，不再靠猜。
