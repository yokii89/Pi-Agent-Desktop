This release adds richer file previews and gives more control over the session workspace.

## File previews

- Preview Word and PowerPoint documents page by page inside PiDesk.
- Preview Excel workbooks, including XLS, XLSX, XLSM, and XLSB files, with sheet navigation and search.
- Select and copy text from Office previews, with document and spreadsheet context preserved.
- Play supported audio and video files directly in the file panel.
- Open Mermaid diagrams as standalone previews with improved rendering and caching.
- Load larger sidebar images more reliably, including images up to 40 MiB.

## Session workspace

- Customize input effects from Personalization settings.
- Navigate question choices more easily with the improved question rail.

## 简体中文

本次更新增强了文件预览能力，并为会话工作区增加了更多自定义选项。

### 文件预览

- 可以在 PiDesk 中逐页预览 Word 和 PowerPoint 文档。
- 可以预览 XLS、XLSX、XLSM 和 XLSB 工作簿，并切换工作表和搜索内容。
- Office 预览支持选择和复制文本，同时保留文档与表格的来源信息。
- 可以直接在文件面板中播放支持的音频和视频文件。
- Mermaid 图表支持独立预览，渲染与缓存更加稳定。
- 侧栏可以更可靠地加载较大的图片，支持最大 40 MiB 的图片。

### 会话工作区

- 可以在「个性化」设置中自定义输入效果。
- 优化问题选项导航，选择和浏览问题更加方便。
