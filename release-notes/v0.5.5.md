A fresh look for the Windows installer: the setup wizard now wears PiDesk's own branding.

## A branded installer

- **The setup wizard gets PiDesk's light-themed branding.** The welcome and finish pages show a custom sidebar artwork with the app logo over soft coral-and-blue waves, and the folder-selection pages carry a matching header banner — replacing the default generic wizard graphics.
- **The uninstall wizard matches too**, so removing PiDesk feels just as deliberate as installing it.
- Nothing else changes: same installer steps, same update flow — only the look.

## 简体中文

Windows 安装器换上新外观：安装向导用上了 PiDesk 自己的品牌视觉。

### 品牌化安装器

- **安装向导采用浅色品牌设计。** 欢迎页与完成页展示自定义侧栏插画——应用 logo 落在珊瑚色与蓝色的柔和波浪上；选择安装路径等中间页也配有同风格的页眉横幅，替代默认的通用向导图形。
- **卸载向导同步换装**，卸载 PiDesk 与安装它一样有仪式感。
- 其余一切不变：安装步骤相同、更新流程相同，只是换上了应用自己的观感。
