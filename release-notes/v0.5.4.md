A lighter release: the installer shrinks by about 40%, and updates start downloading incrementally.

## Smaller downloads

- **The installer is about 40% smaller.** Roughly 160 MB down to 100 MB, by no longer carrying duplicate copies of the interface libraries — everything the app displays is already built into the app bundle, so the extra copies are gone.
- **Updates now download only what changed.** After the first update your client keeps the previous installer locally, and the next update compares against it and downloads only the differing parts — often just a few megabytes instead of the whole package. The very first update after a fresh install still downloads the full installer.
- **Progress shows real bytes.** While downloading, the update panel reads like `42% · 12.3 MB / 38.6 MB`; a total far below the installer size means the incremental download is doing its job.

## Fixes

- **Long-standing installs can check for updates again.** Clients installed from early builds were pointing at a retired repository address and could never see new versions; they now recover automatically and find this release.

The bundled font now ships in a compressed format with no visual difference.

## 简体中文

更轻的一版：安装包缩小约 40%，应用更新开始走增量下载。

### 下载更小

- **安装包缩小约 40%。** 从约 160 MB 降到 100 MB——界面所需的各类库之前被重复装进了安装包，而应用显示所需的一切本就已构建进应用包内，现在重复的副本去掉了。
- **更新只下载变化的部分。** 第一次更新之后，客户端会在本地保留上一个安装包，下次更新先与它比对、只下载差异字节——常常只有几 MB，而不是整个安装包。全新安装后的第一次更新仍是完整下载。
- **进度显示真实字节数。** 下载时更新面板会显示 `42% · 12.3 MB / 38.6 MB` 这样的字样；总量远小于安装包体积，就说明增量下载在生效。

### 修复

- **早期安装的客户端能检查更新了。** 从早期构建安装的客户端一直指向一个已停用的仓库地址，永远看不到新版本；现在会自动恢复，并能看到本版。

随包字体改用压缩格式分发，视觉无任何差异。
