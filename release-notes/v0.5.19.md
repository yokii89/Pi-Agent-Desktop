This release makes it easier to inspect live sessions and keeps context usage up to date while a session is running.

## Improvements

- Open Settings → Live sessions to see all live session processes, including background and prewarmed sessions, with automatic refresh every five seconds.
- Inspect each session's status, process ID, launch source, start time, recent activity, working directory, and session file. Viewing the list does not extend other sessions' idle time.
- Context usage now refreshes during session execution, including long sequences of tool calls, so you can track usage without waiting for the entire response to finish.

## 简体中文

本次更新方便你查看所有存活会话，并让会话执行期间的上下文用量及时更新。

### 改进

- 在设置 →「存活会话」中查看全部存活的会话进程，包括后台会话和预热会话，列表每五秒自动刷新。
- 查看各会话的状态、进程 PID、启动来源、启动时间、最近活动、工作目录和会话文件。查看列表不会延长其他会话的闲置期限。
- 上下文用量现在会在会话执行期间持续刷新，包括连续工具调用期间，无需等整轮回复结束后再查看。
