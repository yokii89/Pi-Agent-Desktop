This update makes changing your wallpaper more reliable and explains when a wallpaper cannot be loaded.

## Wallpaper fixes

- Switching between local wallpapers now loads the selected file reliably, including WebP images.
- If choosing a file, saving your selection, or loading the image or video fails, you now see an error message instead of a silent failure.
- Select the same file again to retry after a loading failure or refresh a file you have replaced.
- If saving your selection fails, your previous wallpaper setting stays active.

## 简体中文

本次更新提升了更换壁纸的可靠性，并在壁纸无法加载时给出明确提示。

### 壁纸修复

- 切换本地壁纸时可以可靠地加载选中的文件，包括 WebP 图片。
- 选择文件、保存设置或加载图片与视频失败时，现在会显示错误提示，不再静默失败。
- 加载失败或替换原文件后，可以重新选择同一个文件重试或刷新。
- 保存选择失败时，保留原来生效的壁纸设置。
