# Buddy 插画维护约定

Buddy 是输入栏边缘的角色插画，设置预览与实际会话共用同一份资源。形象不读取会话数据；业务事件由 `InputBuddy` / `useBuddyMood` 转成姿态。

## 模块职责

| 入口 | 职责 |
| --- | --- |
| `shared/inputBuddy.ts` | 持久化 id、默认值、IPC 白名单与未知值回退；已有 id 不重命名 |
| `BuddyArt.tsx` | 唯一形象注册表；完整映射由 TypeScript 检查；`none` 不渲染 |
| `BuddySvg.tsx` | 画布、描边、姿态属性、装饰语义及动画开关；调用方提供可访问名称 |
| `buddyThinking.ts` | 思考专用 GSAP 时间轴、异步加载清理、减弱动效与可见性暂停 |
| `BuddyAnimal.tsx` | 趴沿动物的身体、五官、双爪；各动物提供毛面、耳朵和配件，长鼻等特征经鼻子插槽扩展 |
| `BuddyExpression` / `BuddyEffects` | 共用特殊表情、问号、睡眠记号与情绪特效 |
| `BuddySnack.tsx` | 按食物标识复用道具，不按动物标识分支 |
| `buddyPose.ts` | 十二种姿态的唯一清单，点击彩蛋由此派生 |

## 绘制与动效

- 画布固定为 `50 0 290 203`，y=203 对齐输入卡沿，线宽默认 5.5，圆端点、圆转角。描边继承 `--buddy-ink`，背景上的记号使用随主题变化的 `--buddy-mark`。
- 角色是分层 SVG 插画资源，不作为 UI 按钮图标使用。按钮、状态控件继续使用 Phosphor。
- 部件通过 `data-part` 接入既有姿态。新动物的共用骨架为 `animal`；旧角色保留各自专属动作。避免给每个新动物复制十二套姿态规则。
- 思考姿态使用 `buddyThinking.ts`，只经 `loadGsap()` 动态加载，节奏集中在 `motionTokens.ts` 的 `BUDDY_THINKING_MOTION`。身体与爪子不缩放、不平移，头部、视线与小部件按「抬眼 → 停顿 → 回正」变化，三点思绪泡代替转圈。思绪泡右缘与独立状态点错开。
- 思考动画只补间消费节点上的 CSS 自定义变量，不改 SVG transform 属性；进入时 CSS 自带完整静态姿态，退出 / 卸载 / 开启减弱动效时用 GSAP context 回滚。延迟加载回调须校验代次，避免退出后重新挂起动画。
- 其余姿态的既有 CSS 循环动作仍集中在 `InputBuddy.module.css`。外层负责定位，内层负责动画；CSS transform 会覆盖同元素的 SVG transform，不能混放。
- SVG 变换原点采用 viewBox 坐标：CSS 的 x 为设计坐标减 50。不同耳根只在动物皮肤中覆盖，避免同权重规则依赖打包顺序。
- 配色与显示尺寸统一登记在 `styles/tokens.css`，动物皮肤仅引用令牌。新动物的本体配色在深浅主题共用。
- `animated={false}` 统一关闭 CSS 与 JS 动画，用于设置缩略图与静态姿态表，不再由调用方另写 CSS 强压动画。
- 减弱动效时保留表情和状态，思考动效同时监听偏好变化；窗口隐藏或 SVG 移出视口暂停，恢复可见后续播，不改全局 ticker。

## 新增形象

1. 在共享清单追加稳定 id，并在中英文文案中追加名称。
2. 实现接收 `BuddyArtworkProps` 的纯插画，使用 `BuddySvg`；同骨架动物优先使用 `BuddyAnimal`。
3. 在 `BuddyArt` 注册一次。设置和输入栏会自动使用新形象。
4. 新增配色只改 tokens；食物优先复用，必要时添加独立食物 id。
5. 检查十二姿态、浅色/深色、实际尺寸、减弱动效与设置静态预览；执行 typecheck、相关 Biome 检查与渲染构建。

当前新增赤狐（白尾尖、草莓）、垂耳兔（丁香围巾、胡萝卜）、熊猫（竹叶胸针、竹子）、小浣熊（环纹尾巴、曲奇）、仓鼠（圆腮帮、葵花籽）、小熊（蓝围巾、蜂蜜罐）、考拉（宽绒耳、桉树叶）。旧形象 id 与默认小狗保持兼容。
