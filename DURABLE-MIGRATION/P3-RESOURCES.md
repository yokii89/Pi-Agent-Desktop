# P3B：技能、提示模板与项目指令

本阶段在 P3A 原生扩展宿主之上接入声明式资源。技能和模板复用现有输入栏补全、用户消息芯片与会话监控，不增加旧 pi 执行路径，也不执行资源包中的旧扩展代码。

## 发现与作用域

主进程从已有设置和包资源列表解析路径，经私有 MessagePort 传给 utility process。运行时再次校验 DTO、文件类型、真实路径、包内包含关系及大小，然后读取一次会话资源快照。

支持的来源：

- 已安装并启用的用户/项目包中的 `skills`、`prompts`，沿用包级和逐项开关。`pi.skills` 可直接指向含 `SKILL.md` 的目录、单个 Markdown 文件或技能集合目录。
- 用户 agent 目录下的 `skills/`、`prompts/` 和用户 `~/.agents/skills/`。
- 当前项目 `.pi/skills/`、`.pi/prompts/` 和 `.agents/skills/`。
- 用户/项目 `settings.skills`、`settings.prompts` 中显式配置的文件或目录；相对路径以相应 settings 所在目录为基准，`~/` 按宿主 home 解析。普通路径包含 glob 时明确报错；现有 `!glob` 排除和 `+`/`-` 精确开关仍按已有匹配器处理。

项目资源覆盖同名用户资源；同一作用域内不同文件重名会拒绝打开，避免扫描顺序决定行为。同一真实文件的重复引用去重。显式本地资源可使用目录链接；包资源不得通过链接越过包根。技能目录递归扫描使用真实路径去重，防止链接环。

资源在会话打开时固定；文件编辑、资源启停和包升级在关闭重开后生效，不在正在运行的任务中热换。当前没有实现 `/reload`。

## 技能

`SKILL.md` 的 `name` 优先作为名称，无名称时使用所在目录名；独立 Markdown 技能使用文件名。命令为 `/skill:<name>`，补全元数据带 `source: skill` 和真实 `filePath`，保留监控卡对技能来源的识别。

系统指令只包含可自动调用技能的名称、描述和路径，提示模型按需用 read 加载正文。`disable-model-invocation: true` 的技能不进入该目录，仍可显式用命令调用。命令展开加入 `<skill>` 块、技能基准目录和原样正文，再附加用户参数；正文中的相对资源路径以技能目录解释。

只解释顶层 `name`、`description`、`disable-model-invocation`。文本支持普通标量、引号及描述的折叠/多行块，不提供通用 YAML 执行或标签能力。描述最多 1,024 字符；补全显示最多 400 字符。名称为最多 64 个字母、数字、下划线或连字符，首字符为字母。

## 提示模板

模板文件名成为 `/<name>`；描述来自 frontmatter，缺省取首个非空正文行。`/steer` 保留给工作台本地队列意图，不能被模板覆盖。模板支持：

| 写法 | 结果 |
| --- | --- |
| `$1`、`$2` | 对应位置的参数 |
| `$@`、`$ARGUMENTS` | 解引用后的全部参数，以空格连接 |
| `${1:-default}`、`${@:-default}` | 参数为空时的默认值 |
| `${@:N}`、`${@:N:L}` | 从第 N 项起的参数，或其中 L 项 |

引号只在参数起始处启用；词内撇号保留，未闭合引号保留为文本，引号内转义同类引号受支持。参数不会进入 shell，也不会把替换结果再次当模板展开。

技能、模板和原生扩展命令共用 admission 重试去重和失败处理。展开结果作为模型输入保存，历史条目同时保留原始命令，界面、列表预览与导出使用用户实际输入。不存在的命令或无效展开明确失败，不将命令原文作为普通问题提交。

## AGENTS.md 与恢复

项目指令按文件系统根目录到当前 cwd 的顺序读取，保留来源路径。每次关闭重开时都重新加载，并在 `Harness.resume()` 前更新应用持有的 conversation instructions；不只在首次创建时读取。因此修改或删除项目指令、启停技能后，恢复任务使用本次打开的资源快照。

直接重附着到仍打开的会话只发送已有权威快照，不刷新正在使用的资源。此次未增加按工具访问目录动态加载下级 AGENTS.md、全局指令文件或任意技能工具权限策略。

## 限制与诊断

- 最多 256 个不同资源；单个资源文件最多 64 KiB，资源正文合计最多 1 MiB，祖先 AGENTS.md 文本预算合计 128 KiB。
- 发现后已启用的文件不可读、元数据无效、重名、包路径逃逸或超限会使会话打开失败。错误使用中英文文案，不包含文件正文或命令参数。
- 本阶段仅提供提示展开，不提供任意副作用命令、设置作用域宿主、View 连接、持久问卷或 Plan gate；这些仍属于后续 P3 工作。
