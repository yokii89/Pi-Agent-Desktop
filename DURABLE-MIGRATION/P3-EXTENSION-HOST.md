# P3A：原生扩展与提示命令

本阶段在现有工作台中提供可运行的 Durable 原生扩展加载与提示命令。接口为 PiDesk 内部预览契约 v1，类型定义见 `src/shared/durableExtension.ts`；尚未作为 npm SDK 发布。

## 清单与发现

复用扩展页已有的用户/项目 `packages` 清单及启停设置，仅加载已安装、已启用且显式声明以下字段的包：

```json
{
  "pidesk": {
    "runtime": {
      "engine": "durable",
      "apiVersion": 1,
      "id": "example",
      "entry": "./dist/desktop.js",
      "capabilities": ["agent", "commands"]
    }
  }
}
```

`id` 为小写字母开头的字母、数字或连字符，最长 64 字符；同一会话中不得重复。入口为包内编译后的 `.js` / `.mjs`，以 ESM 导出默认工厂；`.js` 所在包必须声明 `type: module`。入口不能越过包根，包括符号链接。主进程解析清单，运行时再次检查路径；渲染层不能指定入口。包的原生入口作为独立 extension 资源展示，沿用逐项启停。

缺少原生声明的旧 pi 扩展不执行，扩展页显示兼容诊断。显式声明原生入口但版本、能力、路径或模块无效时，拒绝打开会话，避免缺失审批或工具限制后继续执行。不会通过旧 RPC 兜底。新旧双入口包仍可保留自己的 `pi.extensions`，两者启停相互独立。

## 实例与作用域

默认工厂接收只读 `id`、稳定的存储 `sessionId`、`cwd`、用户/项目 `scope` 和会话关闭信号 `signal`，返回原生 `agent` 定义、`commands` 及可选 `dispose()`。每个顶层会话拥有独立工厂实例和 Registry；模块本身可能被 ESM 缓存，扩展不得在模块全局保存可变的会话状态，也不得修改全局环境变量。

`agent` 使用锁定的 `@earendil-works/pi-durable@1.6.0` Extension 契约，名称必须等于清单 id。工具名和自定义 task 名必须以 `<id>__` 开头，防止覆盖内置工具或其他扩展。hooks、sections 和 wraps 仍遵循 Durable 的原生契约。宿主不注入模型凭证、Electron 或任意 IPC；进程隔离不构成第三方代码沙箱。

首次打开和恢复都会先安装所需定义再恢复 Harness。并发打开同一会话只创建一次实例。关闭先禁止新命令并取消关闭信号，等待在途提示展开，再关闭 Harness，最后按加载逆序释放扩展。加载失败回滚已创建实例；正常关闭、空闲回收和应用退出共用此路径。释放失败保留宿主占用，允许重试，不能交给另一个实例。

扩展启停/升级继续标记已打开会话 stale，关闭并重开后应用，不在正在执行的任务中热换定义。设置作用域宿主、View 连接和持久交互在后续阶段接入。

## 提示命令

命令名为 `<id>:<name>`。工厂返回 `{ name, description, expand(args) }`，其中 `expand` 返回非空提示文本；展开结果作为正常 Durable input 提交，沿用 requestId、插话/稍后队列和 SQLite 持久化。展开必须无外部副作用；同一 requestId 的输入重试共享展开结果，已经接收的输入通过 Durable 自己的幂等记录对账。

命令列表由已打开会话提供，进入现有输入栏补全。不存在的命令和展开失败明确报错，不把命令原文发给模型；普通文本与绝对路径仍按普通输入处理。当前只承诺提示展开，不承诺带任意宿主副作用的通用命令、技能/模板发现或持久交互。展开结果按普通输入展示并保存在会话中。

## 验证

验证范围包括清单版本/能力/路径、启停与作用域、会话实例隔离、命令冲突和未知命令、并发打开、关闭竞态、失败清理、真实原生工具执行，以及 SQLite 关闭重开。使用本机模型服务和独立临时包，不读取实际凭证或更改相邻扩展仓库。
